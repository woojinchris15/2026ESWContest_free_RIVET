# CUBIC-C1
## PROJECT C.U.B.E (Customizable Utility Base for Everyone) 

CUBIC C1​은 소형 장비와 연구 환경을 위한 모듈형 자율주행 로버 플랫폼입니다.

C1은 단순히 주행하는 로봇을 넘어, 수리와 유지보수, 확장성, 모듈화​를 중심으로 설계되었습니다. 알루미늄 프로파일 기반 프레임과 확장 가능한 모듈 구조를 적용하고, Raspberry Pi 5와 RP2350 기반의 분산 제어 시스템을 통해 상위 연산과 실시간 모터 제어를 분리했습니다.

CUBIC C1은 “만들기 쉬운 로봇”보다 “오래 사용하고 다시 고치기 쉬운 로봇”​을 목표로 합니다.
