# Safety & Fail-Safe Test

CUBIC은 상위 제어 시스템 또는 통신에 문제가 발생하더라도
구동계가 계속 동작하는 상황을 방지하기 위해
물리적 Emergency Stop과 Software Communication Watchdog을 구성하였다.

본 시험에서는 두 안전계층의 실제 동작을 반복적으로 확인하였다.

---

# 1. Emergency Stop Test

## 1.1 시험 목적

로봇 주행 중 Emergency Stop을 작동하였을 때
상위 소프트웨어의 상태와 관계없이 모터 구동이 중단되는지 확인하였다.

---

## 1.2 시험 조건

- 로봇 구동 상태에서 시험
- Emergency Stop 반복 작동
- 반복 횟수: **10회**
- 확인 대상: 모터 구동 중단 여부

---

## 1.3 시험 결과

| 시험 | 결과 |
|---|---|
| E-stop 반복 횟수 | 10회 |
| 정상 모터 정지 | **10회** |
| 비정상 동작 | 0회 |

총 10회의 반복 작동에서 **10회 모두 모터 구동이 중단되는 것을 확인하였다.**

---

## 1.4 분석

Emergency Stop은 ROS 2 또는 MCU의 Software Stop 명령과 별개로
구동계의 전원을 차단하는 물리적 안전수단으로 구성되어 있다.

따라서 상위 제어 프로그램의 비정상 동작이나 통신 장애와 관계없이
사용자가 직접 구동계를 정지시킬 수 있다.

본 시험에서는 E-stop의 전기적 응답시간을 별도의 계측 장비로 측정하지 않았으므로,
정량적인 ms 단위 응답시간은 기록하지 않는다.

---

# 2. Communication Loss Fail-Safe Test

## 2.1 시험 목적

상위 제어 장치와 로봇 사이의 통신이 끊어진 상황에서
마지막으로 전달된 주행 명령이 계속 유지되지 않고
Motor Controller의 Watchdog에 의해 로봇이 정지하는지 확인하였다.

---

## 2.2 시험 방법

운용 중인 로봇의 통신 케이블을 물리적으로 분리하는 대신,
사용자가 벽 뒤로 이동하여 무선 통신 신호를 의도적으로 차단하였다.

이를 통해 실제 운용 중 발생할 수 있는
상위 제어 장치와 로봇 사이의 통신 단절 상황을 재현하였다.

시험은 총 **5회 반복**하였다.

---

## 2.3 시험 결과

| 시험 항목 | 결과 |
|---|---:|
| 통신 차단 반복 횟수 | 5회 |
| 통신 단절 후 정상 정지 | **5회** |
| 명령 유지 상태로 계속 주행 | 0회 |

5회의 통신 차단 시험 모두에서
무선 연결이 끊어진 이후 로봇의 구동이 정지하는 것을 확인하였다.

사용자가 관찰하기에는 통신 단절 이후 짧은 시간 내에 정지가 이루어졌으나,
본 시험에서는 정밀 시간측정을 수행하지 않았으므로
실제 정지 응답시간을 정량값으로 기록하지 않는다.

---

# 3. Fail-Safe 구조

CUBIC C1의 주행 안전 구조는 다음과 같이 구성하였다.

```text
Normal Operation
      │
      ├──────── Software Safety
      │
      │   ROS 2 command
      │        │
      │        ▼
      │    Motor MCU
      │        │
      │     Watchdog
      │        │
      │  command timeout
      │        ▼
      │     PWM = 0
      │
      └──────── Hardware Safety

           Emergency Stop
                │
                ▼
         Motor Power Cutoff
````

즉 두 안전계층은 서로 다른 고장 상황을 담당한다.

| 안전 기능                  | 대응 상황           |
| ---------------------- | --------------- |
| Communication Watchdog | 상위 제어기 또는 통신 장애 |
| Emergency Stop         | 사용자의 긴급 물리 정지   |

---

# 4. 시험 결과 요약

| 시험                 | 반복 횟수 |              결과 |
| ------------------ | ----: | --------------: |
| Emergency Stop     |   10회 | **10/10 정상 정지** |
| Communication Loss |    5회 |   **5/5 정상 정지** |

총 15회의 반복 안전 시험에서
모터가 계속 구동되는 비정상 상황은 관찰되지 않았다.

---

# 5. 결론

CUBIC의 Emergency Stop과 Communication Watchdog을 각각 반복적으로 시험한 결과,

* E-stop: **10/10 정상 정지**
* 통신 단절: **5/5 정상 정지**

를 확인하였다.

Emergency Stop은 상위 소프트웨어와 독립적인 물리적 안전수단으로,
Communication Watchdog은 상위 제어 명령이 손실된 경우를 위한 Software Fail-Safe로 동작한다.

이를 통해 단일 정지 방식에 의존하지 않고
서로 다른 고장 상황에 대응하는 두 개의 주행 안전계층이 실제 시스템에서 동작함을 확인하였다.
