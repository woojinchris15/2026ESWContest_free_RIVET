# 하위제어 시스템 상세설명

CUBIC의 하위제어 시스템은 **RP2350 기반 Pico 2 두 개**로 구성되며, 각각 모터 제어(MCU)와 전원 관리(PCU)를 담당한다.

Raspberry Pi 5는 ROS 2와 자율주행 연산을 담당하고, 시간 민감도가 높은 모터 제어와 전원 감시·안전 기능은 별도의 하위제어기에서 독립적으로 처리한다.

두 제어기 모두 듀얼코어 구조를 활용하여 **통신·계측과 실시간 제어·안전 기능을 분리**하였다.

---

## 1. Motor Controller Unit

Motor Controller Unit은 좌·우 모터의 속도 측정, 구동 제어 및 Wheel Odometry 생성을 담당한다.

| Core       | 주요 기능                                                                           |
| ---------- | ------------------------------------------------------------------------------- |
| **Core 0** | micro-ROS 통신, `/cmd_vel` 처리, FG ADC/DMA 측정, 속도 계산, `/odom` 생성, Command Watchdog |
| **Core 1** | 100 Hz 모터 제어, 가감속 제한, Startup 제어, P 제어, 방향 전환 보호, PWM/DIR 출력                    |

### FG Feedback

모터의 FG 신호는 ADC로 취득하며, 두 채널을 **Ping-Pong DMA 방식으로 연속 Sampling**한다.

신호 판별에는 ADC Hysteresis, 연속 Sample 확인, 최소 Edge Interval 제한을 적용하여 노이즈 및 파형 왜곡에 의한 오검출을 줄였다.

```text
FG Signal
   │
   ▼
ADC + DMA
   │
   ▼
Hysteresis Filter
   │
   ▼
Speed Calculation
   │
   ▼
Motor Feedback
```

### Motor Control

`/cmd_vel`의 선속도와 각속도를 좌·우 모터 목표 속도로 변환한 뒤, Core 1에서 실제 모터를 제어한다.

```text
/cmd_vel
   │
   ▼
Wheel Target
   │
   ▼
Acceleration Limit
   │
   ▼
Startup / P Control
   │
   ▼
PWM / DIR
   │
   ▼
 Motor
```

정지 상태에서 안정적으로 모터를 기동하기 위해 One-Shot Startup 제어를 적용했으며, 방향 전환 시에는 PWM을 먼저 감소시키고 실제 속도가 충분히 낮아진 후 DIR을 변경한다.

또한 과속 시 역방향 제동을 사용하지 않고 출력 토크를 줄이는 방식으로 감속하며, PWM 변화에는 Slew Limit을 적용하였다.

### Safety

새로운 `/cmd_vel`이 일정 시간 수신되지 않으면 목표 속도를 자동으로 0으로 설정한다.

micro-ROS Agent 연결이 끊어진 경우에도 기존 이동 명령을 제거하고 자동 재연결을 시도하며, 재연결 후에는 새로운 `/cmd_vel`이 입력되어야 다시 움직일 수 있다.

## 2. Power Controller Unit

Power Controller Unit은 배터리 전압·전류 측정, SOC 계산, Fault 판단 및 Motor Controller의 운전 허가를 담당한다.

| Core       | 주요 기능                                                                    |
| ---------- | ------------------------------------------------------------------------ |
| **Core 0** | Motor RUN/STOP 제어, micro-ROS 통신, Battery/Fault Publish, Buzzer, Watchdog |
| **Core 1** | 전압·전류 계측, 전류 보정·필터링, Coulomb Counting, SOC 계산, 저전압 및 Fault 판단            |

### Power Monitoring

INA226을 이용하여 배터리 전압을 측정하고, WCS1800의 출력을 ADC로 측정하여 소비 전류를 계산한다.

부팅 시 전류 센서의 영점을 자동 보정하고, 측정값에 Deadband와 Low-Pass Filter를 적용한다.

배터리 SOC는 초기 전압을 기준으로 추정한 뒤, 소비 전류를 적산하는 Coulomb Counting 방식으로 갱신한다.

```text
Voltage / Current
       │
       ▼
Filtering
       │
       ▼
SOC Calculation
       │
       ▼
Power State
```

전압, SOC 및 센서 상태를 기반으로 `RUNNING`, `LOW_BATTERY`, `CRITICAL_BATTERY`, `FAULT` 상태를 구분하며, Critical 또는 Fault 상태에서는 모터 구동을 허용하지 않는다.

---

## 3. MCU–PCU Safety Link

PCU와 MCU는 Raspberry Pi를 거치지 않는 **전용 UART 안전 통신 경로**로 연결된다.

PCU는 부팅 직후 MCU에 `STOP`을 전달하고, 전원 상태 확인이 정상적으로 완료된 경우에만 `RUN`을 전달한다.

```text
PCU
 │
 ├── RUN ──► MCU Drive Enable
 │
 └── STOP ─► MCU Hard-Stop
```

PCU의 `STOP`이 입력되면 MCU에서는 일반적인 제어 경로보다 우선하는 Hard-Stop을 활성화하여 PWM을 즉시 0으로 만든다.

`RUN`이 다시 입력되더라도 이전 주행 명령은 복원하지 않으며, 새로운 `/cmd_vel`이 입력되어야 다시 주행한다.

## 4. Fail-Safe 구조

하위제어단에는 여러 단계의 안전 기능을 적용하였다.

| 조건                   | 동작                      |
| -------------------- | ----------------------- |
| `/cmd_vel` Timeout   | Motor Target 0          |
| micro-ROS Agent Loss | 기존 명령 제거 및 자동 재연결       |
| PCU Critical / Fault | MCU Hard-Stop           |
| PCU Core 1 이상        | Hardware Watchdog Reset |
| PCU 재부팅              | 초기 상태에서 MCU STOP        |

이를 통해 ROS 2 또는 Raspberry Pi의 상태와 관계없이 기본적인 구동 정지와 전원 안전 기능이 하위제어단에서 독립적으로 유지되도록 설계하였다.

---

## 5. 전체 하위제어 구조

```text
                 Raspberry Pi 5
                      │
                   ROS 2
                      │
              ┌───────┴───────┐
              │               │
              ▼               ▼
       Motor Controller   Power Controller
           Pico 2             Pico 2
              │               │
       ┌──────┴──────┐  ┌─────┴─────┐
       │             │  │           │
     Core 0        Core 1 Core 0   Core 1
   통신·FG처리     모터제어 안전·통신 전력계측
       │             │     │         │
       └──────┬──────┘     └────┬────┘
              ▼                 │
            Motors ◄── RUN/STOP ┘
```

CUBIC의 하위제어 시스템은 구동 제어와 전원 안전 기능을 상위 ROS 2 시스템과 분리하여, 통신 상태와 관계없이 핵심 제어 및 안전 기능을 유지하도록 구성하였다.
