# CUBIC Mechanical Integration

CUBIC은 다양한 실험 장비의 장착과 반복적인 구조 변경을 고려하여 **알루미늄 프로파일 기반의 가변 구조와 표준화된 체결·배선 방식**을 적용하였다.

특정 장비에 종속되지 않고 센서, 제어기 및 추가 모듈을 쉽게 장착·교체할 수 있는 구조를 목표로 설계하였다.

---

## 1. Frame & Adjustable Mount

CUBIC의 기본 골격은 **알루미늄 프로파일**로 구성하였다.

프로파일의 슬롯 구조를 이용하면 별도의 프레임 재가공 없이 부품 위치를 변경하거나 새로운 구조물을 추가할 수 있어, 반복적인 변경이 필요한 연구·개발용 플랫폼에 적합하다.

차체 상단에는 모듈 장착을 위한 **2개의 가변형 지지 프로파일**을 배치하였다. 고정 볼트를 풀어 지지대 사이의 간격을 조절할 수 있어 탑재하려는 장비의 크기와 체결 위치에 맞추어 사용할 수 있다.

이를 통해 특정 규격의 전용 마운트를 제작하지 않고도 다양한 센서와 실험용 구조물을 장착할 수 있도록 하였다.

---

## 2. External Module Interface

상단에는 추가 모듈 연결을 위한 **RJ45 및 XT60 포트**를 배치하였다.

| 인터페이스      | 역할                 |
| ---------- | ------------------ |
| RJ45       | 외부 장치와의 유선 네트워크 연결 |
| XT60       | 추가 모듈의 전원 연결       |
| 가변 지지 프로파일 | 모듈의 기계적 장착         |

RJ45 포트를 통해 외부 컴퓨팅 장치나 개발용 PC를 CUBIC의 네트워크에 연결할 수 있으며, XT60 포트는 추가 장비의 전원 연결부로 사용할 수 있다.

따라서 상단부는 단순한 적재 공간이 아니라 **기계적 장착, 통신, 전원 연결을 함께 제공하는 모듈 확장부**로 구성하였다.

---

## 3. Fastener Standardization

프로파일 전용 체결부를 제외한 일반 기계 체결부는 가능한 한 **육각렌치볼트 계열로 통일**하였다.

여러 종류의 나사와 공구를 혼용하지 않도록 하여 조립 및 정비 시 필요한 공구 종류를 줄이고 반복적인 분해·조립을 단순화하였다.

| 구분        | 체결 방식          |
| --------- | -------------- |
| 일반 기계 체결부 | 육각렌치볼트         |
| 알루미늄 프로파일 | T너트 및 프로파일용 볼트 |

---

## 4. Wiring & Harness

내부 배선은 직접 납땜하여 고정하는 방식을 최소화하고 **압착단자와 커넥터 기반의 배선 하네스**를 적용하였다.

주요 내부 연결에는 **JST XH 2.54 및 SM 2.54 계열 커넥터**를 사용하여 센서나 제어기를 교체할 때 기존 배선을 절단하거나 다시 납땜하지 않고 분리할 수 있도록 구성하였다.

| 방식          | 적용 목적               |
| ----------- | ------------------- |
| 압착단자        | 안정적인 배선 체결 및 재작업 감소 |
| JST XH 2.54 | PCB 및 내부 신호 연결      |
| SM 2.54     | 모듈 및 하네스 분리         |
| 커넥터 기반 배선   | 장치 단위 교체 및 유지보수     |

---

## 5. Design Summary

CUBIC의 기계적 통합 구조는 **개조성, 확장성 및 정비성**을 중심으로 설계하였다.

| 설계 요소    | 적용 방법               |
| -------- | ------------------- |
| 구조 변경성   | 알루미늄 프로파일 프레임       |
| 상부 확장성   | 가변형 지지 프로파일 2개      |
| 모듈 인터페이스 | RJ45 네트워크 + XT60 전원 |
| 체결 표준화   | 육각렌치볼트 중심의 체결 방식    |
| 배선 정비성   | 압착단자 및 커넥터 기반 하네스   |

이를 통해 CUBIC은 하나의 고정된 완성품보다, **사용 목적에 따라 장비와 구조를 변경할 수 있는 모듈형 연구·개발 플랫폼**을 지향한다.
